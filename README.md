# Yicai Developer Portfolio

A single-page developer portfolio built with Next.js, React, TypeScript, and custom CSS.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Customize first

- Replace the placeholder email in `app/page.tsx`.
- Replace LinkedIn and GitHub URLs.
- Add `public/resume.pdf`.
- Replace project placeholder panels with screenshots.
- Replace the hero initials with a portrait or illustration when ready.
